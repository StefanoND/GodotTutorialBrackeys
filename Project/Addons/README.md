# Addons

This is what Godot expects you to call the folder which houses 3rd-party engine
plugins.

It'll be used for that purpose, as well as any 3rd-party code (from the Asset
Store, the internet, etc) that will be used exactly as-is in the game code.

Even though it's not the best name for code serving this latter purpose. It's
better to keep all third-party code in a single location instead of using two
accurately-named directories. Keeping the top-level structure simpler.
