# Entities

Entities directory is where all game objects that is meant to be rendered
visually within the game will be, such as the player character, enemies,
projectiles, decorative objects, etc. As with the rest of game_objects, the
specific structure of the entities directory must be adapted to whatever
structure makes sense for the particular project it's being worked on.

Some directories that might be used are:

- characters
  - player character
  - npcs
- interactables
- collectables
- decorations
- effects
- projectiles
