# Version Control

Version control is paramount in any project.

All SCM here are industry-standard depending on size and complexity of the
project and people involved.

There are other SCMs, but they're not "good enough" for Game Development.

## Free (Individual/Small teams: < 10)

- Git for code
- Subversion (SVN) for binaries (images, models, etc)

## Cheap (Small/Medium teams: < 100)

- Plastic SCM for code and binaries

## Expensive (Large teams: > 100)

- Perforce for code and binaries
